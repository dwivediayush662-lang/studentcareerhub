REACT.JS INTERVIEW

20 React.js Interview Questions for Freshers in 2026

Prepare for React.js interviews with important questions, simple explanations and practical preparation tips.

React is a popular JavaScript library for building user interfaces. It is widely used for creating component-based web applications. Freshers are commonly asked questions about JSX, components, props, state, hooks and rendering.

Interview Tip: Don't only memorize React definitions. Build a small React project and practice explaining components, state, props and hooks.

1. What is React?

Answer

React is a JavaScript library for building user interfaces. It encourages developers to create reusable UI components.

2. What are React components?

Answer

Components are reusable building blocks of a React application. A component can contain UI structure, logic and behavior.

3. What is JSX?

Answer

JSX is a syntax extension commonly used with React that allows developers to describe UI using a JavaScript-like syntax. It is transformed into JavaScript during the build process.

Example:

const element = <h1>Hello React</h1>;

4. What are props in React?

Answer

Props are inputs passed from a parent component to a child component. They are read-only from the receiving component's perspective.

5. What is state in React?

Answer

State represents data managed by a component that can change over time. Updating state can cause React to render the component again.

6. What is useState?

Answer

useState is a React Hook that allows a function component to add and manage state.

Example:

const [count, setCount] = useState(0);

7. What is useEffect?

Answer

useEffect is a React Hook used to synchronize a component with external systems, such as network requests, subscriptions or browser APIs.

8. What are React Hooks?

Answer

Hooks are functions provided by React that let function components use features such as state and effects. Examples include useState, useEffect, useContext and useRef.

9. What is the Virtual DOM?

Answer

The Virtual DOM is a conceptual representation of the UI that React uses when determining what changes need to be reflected in the actual DOM. React can then update the necessary parts of the browser DOM.

10. What is conditional rendering?

Answer

Conditional rendering means displaying different UI depending on a condition.

Example:

{isLoggedIn ? <Dashboard /> : <Login />}

11. How do you render a list in React?

Answer

Lists are commonly rendered by using JavaScript methods such as map() to transform an array into React elements.

Example:

users.map(user => <li key={user.id}>{user.name}</li>)

12. Why are keys used in React lists?

Answer

Keys help React identify list items between renders. A key should be stable and unique among the relevant siblings.

13. What is event handling in React?

Answer

React supports event handlers such as onClick, onChange and onSubmit. Event handlers are normally passed functions that should run when the event occurs.

14. What is a controlled component?

Answer

A controlled form element has its current value controlled by React state. This gives the component explicit control over form data.

15. What is React Router?

Answer

React Router is a routing library commonly used to manage navigation and URL-based views in React applications.

16. What is useContext?

Answer

useContext is a React Hook that allows a component to read values from a React context without manually passing those values through every intermediate component.

17. What is useRef?

Answer

useRef returns a mutable reference object whose value persists between renders. It is commonly used to access DOM elements or store values that do not need to trigger a render when changed.

18. What is lifting state up?

Answer

Lifting state up means moving shared state to the closest common parent component so that multiple child components can use the same source of truth.

19. How can React application performance be improved?

Answer

Performance can be improved by avoiding unnecessary renders, keeping component state focused, using appropriate memoization when useful, optimizing large lists and reducing unnecessary work.

20. Why is React popular?

Answer

React is popular because it provides reusable components, a declarative approach to UI development, a large ecosystem and strong support for building modern interactive web applications.

React.js Interview Preparation Tips

✔ Learn JavaScript fundamentals first.
✔ Understand components and JSX.
✔ Practice props and state.
✔ Learn useState and useEffect.
✔ Practice rendering lists and handling events.
✔ Understand forms and controlled components.
✔ Build at least one React project.
✔ Practice explaining your project in interviews.
