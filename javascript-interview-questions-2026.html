20 JavaScript Interview Questions for Freshers in 2026

Prepare for JavaScript interviews with important questions, simple explanations and practical preparation tips.

JavaScript is one of the most important technologies for modern web development. It is widely used for creating interactive websites and web applications. Freshers are commonly asked questions about variables, functions, arrays, objects, DOM, promises and asynchronous programming.

Interview Tip: Don't only memorize JavaScript definitions. Practice writing small programs and understand how your code behaves in the browser.

1. What is JavaScript?

Answer

JavaScript is a programming language commonly used to add logic and interactivity to websites and web applications. It can run in browsers and also in server-side environments such as Node.js.

2. What are variables in JavaScript?

Answer

Variables are names used to store or reference values. Modern JavaScript commonly uses let and const, while var is an older declaration form.

3. What is the difference between var, let and const?

Answer

var is function-scoped and has older hoisting behavior.

let and const are block-scoped.

A variable declared with const cannot be reassigned after initialization.

4. What are JavaScript data types?

Answer

JavaScript has primitive types such as string, number, bigint, boolean, undefined, symbol and null. Objects are used for collections of data and more complex structures.

5. What is the difference between == and ===?

Answer

== performs loose equality comparison and may convert types before comparing.

=== performs strict equality comparison and does not perform that implicit type conversion.

6. What is a function?

Answer

A function is a reusable block of code that can accept input through parameters and optionally return a result.

Example:

function add(a, b) {
    return a + b;
}

7. What is an arrow function?

Answer

An arrow function is a shorter function syntax introduced in modern JavaScript. Arrow functions also have different rules for the this value compared with regular functions.

Example:

const add = (a, b) => a + b;

8. What is an array?

Answer

An array is an ordered collection that can contain multiple values. JavaScript arrays can contain values of different types.

Example:

const fruits = ["Apple", "Mango", "Banana"];

9. What is an object?

Answer

An object is a collection of properties. Properties can store values, including functions.

Example:

const student = {
    name: "Ayush",
    age: 20
};

10. What is the DOM?

Answer

DOM stands for Document Object Model. It represents a web page as a tree of objects that JavaScript can access and manipulate.

11. What is an event in JavaScript?

Answer

An event represents an occurrence that code can respond to, such as a click, keyboard input or form submission.

12. What is a callback function?

Answer

A callback is a function passed to another function so that it can be called later or when a particular operation is completed.

13. What is a Promise?

Answer

A Promise represents the eventual completion or failure of an asynchronous operation. It can be in pending, fulfilled or rejected state.

14. What is async/await?

Answer

async and await provide a convenient syntax for working with Promises. An async function returns a Promise, and await pauses that function until a Promise settles.

15. What is hoisting?

Answer

Hoisting describes JavaScript's handling of certain declarations before execution of the surrounding code. The exact behavior differs for var, let, const and function declarations.

16. What is scope?

Answer

Scope determines where variables and other declarations can be accessed. JavaScript commonly has global, function and block scopes.

17. What is a closure?

Answer

A closure occurs when a function retains access to variables from its surrounding lexical environment, even after the outer function has finished running.

18. What is JSON?

Answer

JSON stands for JavaScript Object Notation. It is a text-based data format commonly used for exchanging structured data between applications.

19. What is localStorage?

Answer

localStorage is a browser storage mechanism that allows web applications to store string data persistently for the site's origin until it is cleared or removed.

20. What is the difference between synchronous and asynchronous JavaScript?

Answer

Synchronous code generally executes one operation after another in sequence. Asynchronous programming allows certain operations to complete later while other work can continue, commonly using Promises, async/await and event-based APIs.

JavaScript Interview Preparation Tips

✔ Understand variables and data types.
✔ Practice arrays and objects.
✔ Learn functions and arrow functions.
✔ Understand DOM manipulation.
✔ Practice JavaScript events.
✔ Learn Promises and async/await.
✔ Understand scope and closures.
✔ Build small JavaScript projects.
✔ Practice explaining your code during interviews.
