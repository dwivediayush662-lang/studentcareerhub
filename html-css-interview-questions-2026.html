20 HTML & CSS Interview Questions for Freshers in 2026

Prepare for web development interviews with important HTML and CSS questions, simple answers and practical tips.

HTML and CSS are fundamental technologies for front-end web development. Freshers are commonly asked questions about HTML elements, forms, semantic markup, CSS selectors, Flexbox, Grid and responsive design.

Interview Tip: Don't only memorize definitions. Build small web pages and be prepared to explain how your HTML structure and CSS styles work.

1. What is HTML?

Answer

HTML stands for HyperText Markup Language. It is the standard markup language used to structure content on web pages.

2. What is CSS?

Answer

CSS stands for Cascading Style Sheets. It is used to control the presentation and layout of HTML documents, including spacing, typography and responsive layouts.

3. What are HTML elements?

Answer

An HTML element generally consists of a start tag, content and an end tag. Some elements are void elements and do not have closing tags, such as img and input.

4. What are semantic HTML elements?

Answer

Semantic elements describe the meaning or purpose of their content. Examples include header, nav, main, section, article, aside and footer.

5. What is the difference between div and span?

Answer

The div element is commonly used as a generic block-level container, while span is commonly used as a generic inline container. Their actual layout can be changed with CSS.

6. What is an HTML attribute?

Answer

An attribute provides additional information about an HTML element. Common examples include href, src, alt, id and class.

7. What is the purpose of the alt attribute?

Answer

The alt attribute provides alternative text for an image. It can help users who cannot see the image and can also provide useful information when the image cannot be loaded.

8. What is an HTML form?

Answer

An HTML form provides controls that allow users to enter and submit information. Common controls include input, textarea, select and button.

9. What is the difference between id and class?

Answer

An id is intended to uniquely identify an element within a document, while a class can be assigned to multiple elements for shared styling or behavior.

10. What are CSS selectors?

Answer

CSS selectors are patterns used to select HTML elements that should receive particular styles. Examples include element selectors, class selectors, id selectors, attribute selectors and pseudo-classes.

11. What is the CSS box model?

Answer

The CSS box model describes an element as content surrounded by padding, border and margin.

12. What is the difference between margin and padding?

Answer

Padding is the space between an element's content and its border. Margin is the space outside the element's border.

13. What is Flexbox?

Answer

Flexbox is a CSS layout model designed to arrange elements efficiently along one dimension, either as a row or a column. It is useful for alignment, spacing and flexible layouts.

14. What is CSS Grid?

Answer

CSS Grid is a two-dimensional layout system that allows developers to arrange elements in rows and columns.

15. What is responsive web design?

Answer

Responsive web design is an approach that allows websites to adapt their layout and content to different screen sizes and devices.

16. What are media queries?

Answer

Media queries allow CSS rules to be applied conditionally based on characteristics such as viewport width. They are commonly used to create responsive layouts.

Example:

@media (max-width: 600px) {
    body {
        font-size: 16px;
    }
}

17. What is the difference between display: none and visibility: hidden?

Answer

display: none removes the element from the layout. visibility: hidden makes the element invisible while generally preserving its layout space.

18. What is CSS specificity?

Answer

Specificity is the mechanism browsers use to determine which competing CSS declarations should apply to an element. Selectors such as inline styles, IDs, classes and element selectors have different levels of specificity.

19. What is the difference between block and inline elements?

Answer

Block-level elements generally start on a new line and can occupy the available width, while inline elements generally flow within surrounding text. CSS can change an element's display behavior.

20. Why are HTML and CSS important in web development?

Answer

HTML provides the structure and meaning of web content, while CSS controls its presentation and layout. Together they form the foundation of front-end web development.

HTML & CSS Interview Preparation Tips

✔ Learn semantic HTML.
✔ Practice forms and input elements.
✔ Understand the CSS box model.
✔ Practice Flexbox and Grid.
✔ Learn responsive design.
✔ Understand selectors and specificity.
✔ Build responsive mini-projects.
✔ Practice explaining your code clearly.
