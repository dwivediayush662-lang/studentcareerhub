20 SQL Interview Questions for Freshers in 2026

Prepare for SQL and database interviews with important questions, simple answers and practical tips.

SQL is one of the most important skills for software developers, data analysts, database administrators and many other technology roles. Freshers are commonly asked questions about queries, keys, joins, normalization and database concepts.

Interview Tip: Don't only memorize SQL definitions. Practice writing queries using sample tables and understand why each query works.

1. What is SQL?

Answer

SQL stands for Structured Query Language. It is commonly used to create, read, update and manage data stored in relational database systems.

2. What is a database?

Answer

A database is an organized collection of data that can be stored, accessed and managed efficiently. Relational databases organize data primarily in tables.

3. What is a table?

Answer

A table is a structure in a relational database that stores data in rows and columns. Each row generally represents a record and each column represents an attribute.

4. What is a Primary Key?

Answer

A primary key is a column or set of columns used to uniquely identify each row in a table. A primary key cannot contain NULL values.

5. What is a Foreign Key?

Answer

A foreign key is a column or set of columns that references a key in another table. It is commonly used to establish relationships between tables.

6. What is the SELECT statement?

Answer

SELECT is used to retrieve data from one or more tables.

Example:

SELECT name, salary FROM employees;

7. What is the WHERE clause?

Answer

The WHERE clause filters rows based on a specified condition.

Example:

SELECT * FROM employees WHERE salary > 30000;

8. What is a JOIN?

Answer

A JOIN combines related data from two or more tables using a matching condition.

Common types include INNER JOIN, LEFT JOIN, RIGHT JOIN and FULL OUTER JOIN, depending on the database system.

9. What is an INNER JOIN?

Answer

INNER JOIN returns rows where the join condition matches in both tables.

Example:

SELECT employees.name, departments.name FROM employees INNER JOIN departments ON employees.department_id = departments.id;

10. What is GROUP BY?

Answer

GROUP BY groups rows that have the same values in specified columns. It is often used with aggregate functions such as COUNT, SUM, AVG, MIN and MAX.

11. What is the difference between WHERE and HAVING?

Answer

WHERE filters individual rows before grouping, while HAVING filters groups after GROUP BY has been applied.

12. What are aggregate functions?

Answer

Aggregate functions perform calculations on a set of rows and return a single result. Common examples are COUNT(), SUM(), AVG(), MIN() and MAX().

13. What is normalization?

Answer

Normalization is a database design technique used to organize data and reduce unnecessary duplication. It commonly involves normal forms such as 1NF, 2NF and 3NF.

14. What is the difference between DELETE, TRUNCATE and DROP?

Answer

DELETE removes selected rows and can use a WHERE condition.

TRUNCATE removes all rows from a table while keeping the table structure.

DROP removes the database object itself, such as a table.

15. What is a NULL value?

Answer

NULL represents a missing, unknown or unavailable value. It is different from zero, an empty string or the value FALSE.

16. What is a UNIQUE constraint?

Answer

A UNIQUE constraint ensures that values in a specified column or group of columns do not contain duplicates, subject to the database system's rules regarding NULL values.

17. What is an index in SQL?

Answer

An index is a database structure that can improve the speed of data retrieval for suitable queries. Indexes can improve read performance but may require additional storage and can add overhead to data modifications.

18. What is a subquery?

Answer

A subquery is a query nested inside another SQL statement. It can be used to provide intermediate results for the outer query.

19. What is a view?

Answer

A view is a database object that presents the result of a stored query as a virtual table. It can simplify complex queries and help control access to underlying data.

20. What is the difference between SQL and MySQL?

Answer

SQL is a language used to work with relational databases. MySQL is a relational database management system that supports SQL and provides features for storing and managing data.

SQL Interview Preparation Tips

✔ Practice SELECT queries regularly.
✔ Understand different types of JOINs.
✔ Learn primary and foreign keys.
✔ Practice GROUP BY and aggregate functions.
✔ Understand normalization basics.
✔ Practice queries using sample databases.
✔ Learn to explain your query step-by-step.
✔ Revise database concepts before the interview.
