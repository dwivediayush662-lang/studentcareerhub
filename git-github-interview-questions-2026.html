GIT & GITHUB INTERVIEW

20 Git & GitHub Interview Questions for Freshers in 2026

Prepare for Git and GitHub interviews with important questions, simple answers and practical command examples.

Git is a distributed version control system used to track changes in source code, while GitHub is a platform for hosting Git repositories and collaborating on software projects.

Interview Tip: Don't only memorize Git commands. Practice creating a repository, making commits, creating branches and pushing your project to GitHub.

1. What is Git?

Answer

Git is a distributed version control system used to track changes in files and coordinate work among developers.

2. What is GitHub?

Answer

GitHub is a web-based platform that hosts Git repositories and provides collaboration features such as pull requests, issues and code review.

3. What is the difference between Git and GitHub?

Answer

Git is the version control system itself. GitHub is an online platform that can host Git repositories and provide collaboration and project management features.

4. What is a Git repository?

Answer

A Git repository is a directory containing project files and Git's version-control data used to track changes and history.

5. What does git init do?

Answer

The git init command initializes a new Git repository in the current directory.

git init

6. What does git clone do?

Answer

git clone creates a local copy of an existing repository, including its tracked history.

git clone <repository-url>

7. What does git status do?

Answer

git status shows information about the current repository state, including modified files, staged changes and the current branch.

git status

8. What does git add do?

Answer

git add stages changes so they can be included in the next commit.

git add .

9. What does git commit do?

Answer

git commit records the currently staged changes in the repository history with a commit message.

git commit -m "Add new article"

10. What does git push do?

Answer

git push sends local commits to a remote repository.

git push origin main

11. What does git pull do?

Answer

git pull retrieves changes from a remote repository and integrates them into the current local branch.

git pull origin main

12. What is a Git branch?

Answer

A branch is a separate line of development in a repository. Branches allow developers to work on features or fixes without directly changing another branch.

git branch feature-login

13. What is git checkout or git switch used for?

Answer

These commands can be used to switch between branches. The newer git switch command is designed specifically for branch switching.

git switch feature-login

14. What is git merge?

Answer

git merge combines the changes from one branch into another branch.

git switch main
git merge feature-login

15. What is a pull request?

Answer

A pull request is a collaboration mechanism on platforms such as GitHub where developers propose changes from one branch or repository for review and integration into another branch.

16. What is a merge conflict?

Answer

A merge conflict occurs when Git cannot automatically combine changes, often because different branches modified the same part of a file.

The developer must review the conflicting sections, choose the correct content and then complete the merge.

17. What is .gitignore?

Answer

The .gitignore file specifies files and directories that Git should normally ignore when detecting untracked files.

Common examples include dependency folders, generated files and local environment configuration.

18. What does git log do?

Answer

git log displays the commit history of a repository.

git log --oneline

19. What is a remote repository?

Answer

A remote repository is a repository stored at another location, commonly on a hosting service. Local Git repositories can communicate with remotes using commands such as fetch, pull and push.

git remote -v

20. Why is Git important for developers?

Answer

Git helps developers track changes, collaborate on projects, maintain history and work safely on different features or fixes. It is an important tool in modern software development.

Git & GitHub Interview Preparation Tips

✔ Learn the basic Git workflow.
✔ Practice init, add, commit and push.
✔ Understand branches and merging.
✔ Learn how pull requests work.
✔ Practice resolving simple merge conflicts.
✔ Understand .gitignore.
✔ Learn how to inspect commit history.
✔ Create and maintain your own GitHub projects.
